# Curved-wall reflection - 30 October 2026

Solid cells still identify the body interior. At each fluid-solid lattice link, a quadratic sphere intersection supplies the wall distance q as a fraction of the full link. The linear Bouzidi/Firdaouss/Lallemand treatment replaces a halfway wall: for q<0.5, interpolate outgoing populations at the boundary fluid node and the next node away from the wall; for q>=0.5, interpolate local outgoing and incoming populations. At q=0.5 this reduces to halfway reflection. See [OpenLB boundary documentation](https://openlb.gitlab.io/release/content/06_initial_boundary.html).

Distances are prepared once. Only boundary fluid nodes store 19 values; upper flag bits index these records, while bits 0-2 retain solid/inlet/outlet flags. An unresolved gap without the required second fluid sample falls back to halfway reflection. Current convex spheres have a valid sample. The `halfway` solver setting remains for historical comparisons. Future imported models need their own robust link-surface intersection routine; this milestone handles spheres.

The force pass sums outgoing plus actual interpolated returned populations along each body-facing link, with constant reference-pressure subtraction. It shares the GPU reflection expression with the flow pass. The simple 2*f_outgoing expression remains correct only at halfway reflection. This link force check is not a proof of exact global momentum or mass conservation for interpolated boundaries.

Two focused checks validate that intersections lie on the analytical sphere and exercise both q branches, then compare asymmetric GPU populations and forces to an independent double-precision CPU reference over 23 steps, followed by reset/rest. The legacy halfway force/momentum test explicitly selects halfway treatment. No long resolution or drag sweeps were run for this milestone. Subcell-translation sensitivity, global mass drift and drag/domain convergence still need a later targeted study before claiming improved quantitative accuracy. Older saved drag studies predate this boundary change.
